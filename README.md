# Social Media Application(in progress)

## Description

This is a simple social media application built using Spring Boot, Hibernate, and PostgreSQL. The application allows users to create and view posts, follow other users, and like posts. Each post has a title, body, and author.

## Features

- User registration and authentication
- Create, view, and delete posts
- Follow and unfollow users
- Like and unlike posts

## Technologies Used

- Spring Boot
- Hibernate
- PostgreSQL
- JUnit and Mockito for testing

## Setup Instructions

1. Clone the repository
2. Create new db in PostgreSQL
3. Set up spring.datasource.[username, url, password] in application.properties
4. Run ./mvnw spring-boot:run
